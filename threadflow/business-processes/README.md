# 📋 ThreadFlow ERP — ডোমেন-ভিত্তিক বিজনেস প্রসেস স্পেসিফিকেশন (Domain-Wise Architecture)

> এই ডিরেক্টরিতে প্রতিটি ডোমেনের জন্য **আলাদা ডেডিকেটেড ফোল্ডার** রয়েছে, যাতে প্রতিটি ডিপার্টমেন্টের রুলস, ফর্মুলা, ডকুমেন্টস ও সাব-প্রসেস সম্পূর্ণ আলাদা ও সুসংগঠিত থাকে।
